# Commercial Module Entitlement Map

- ACCOUNTING: accounts, accounting settings/engine, journals, general ledger
- INVENTORY: items, categories, warehouses, inventory, stock ledger, costing engine, revaluation, adjustments, inventory policy/valuation/aging
- SALES: customers, quotations, sales orders, delivery notes, invoices, customer payments, sales returns
- PURCHASE: suppliers, purchase orders, goods receipts, invoices, supplier payments, returns, landed costs
- MANUFACTURING: BOM, production orders, material consumption, finished goods, MRP, scheduling, capacity, quality, maintenance
- WIP: manufacturing WIP accounting
- COSTING: production variance and costing variance
- VAT: VAT engine and settlement
- ASSET_MANAGEMENT: assets, depreciation, disposal
- BANK_RECONCILIATION: bank reconciliation
- REPORTING: advanced reporting, aged AP/AR, balance sheet, cash flow, statements, management dashboard, P&L, trial balance
- MOBILE_APP: mobile API surface
- API_ACCESS: Tally integration API surface
- NOTIFICATIONS: notifications API
