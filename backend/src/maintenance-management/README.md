# Maintenance Management

Self-contained module providing:
- Machine/asset register
- Preventive maintenance plans
- Maintenance work orders
- Downtime logging
- Maintenance KPI report
- Labor + parts maintenance costs
- Asset next-maintenance date tracking
- Company isolation
- UUID PKs
- Soft delete for asset and plan masters

This module intentionally does not link to accounting fixed assets because no
verified fixed-asset entity was found in the current project artifacts.
